# 📥 YouTube / Instagram to MP4 Downloader

A powerful video downloader that allows users to convert and download videos from YouTube and Instagram directly into MP4 format.

🌐 **Live Preview:**  
https://k911soham-prog.github.io/yt-mp4-converter/

> The preview page contains a link to the main production website.

---

## 🚀 Features

- Download YouTube videos
- Download YouTube Shorts
- Download Instagram Reels
- Fast MP4 conversion
- Backend-powered processing
- Includes executable (.exe) components for video extraction and conversion
- Supports public content only (private videos are not supported)

---

## 🛠 Project Overview

This project consists of:

- A frontend preview interface hosted on GitHub Pages  
- A backend system that handles video processing and conversion  
- Executable (.exe) tools responsible for media extraction and MP4 conversion  

The GitHub Pages site serves as a preview interface and provides access to the main website where full functionality is available.

---

## ⚙️ How It Works

1. User provides a public YouTube or Instagram link.
2. The backend processes the video.
3. The system converts it into MP4 format.
4. The user downloads the converted file.
